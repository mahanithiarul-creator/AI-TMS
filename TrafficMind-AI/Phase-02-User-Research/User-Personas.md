# TrafficMind AI: User Personas

## Research Note

These provisional personas synthesize the operational conditions identified in Phase 01. They are not substitutes for interviews or observation and must be validated before product requirements are approved.

## 1. Asha Rao - Traffic Control Center Operator

| Attribute | Detail |
|---|---|
| Age / occupation | 34 / Traffic Control Center Operator |
| Technical skill | High with traffic systems; moderate with analytics tools |
| Goals | Detect disruptions early, coordinate a safe response, maintain corridor flow. |
| Pain points | Too many disconnected feeds; uncertain alert quality; difficult handoffs. |
| Motivations / frustrations | Wants calm, defensible decisions; frustrated by late or false information. |
| Daily workflow | Reviews network status, monitors peak periods, verifies incidents, coordinates action, records outcomes. |
| Technology / current tools | CCTV wall, radios, signal console, incident log, phone, messaging tools. |
| Decision making | Escalates safety-critical events; acts within approved operational playbooks. |
| Success definition | A verified event reaches the right responder quickly and disruption is resolved safely. |
| Quote | "I need confidence in what is happening before I redirect a whole corridor." |
